# Бортик

Учёт тренировок, посещений и расчётов с начальником для тренера школы плавания.

Одна страница без сборки и зависимостей. Работает офлайн: данные пишутся в
браузер мгновенно, на сервер уходят фоном, когда есть связь.

## Развёртывание

### 1. База (Supabase, бесплатно)

1. Зарегистрироваться на supabase.com, создать проект (регион Frankfurt).
2. SQL Editor → вставить целиком [schema.sql](schema.sql) → Run.
3. Project Settings → API → скопировать **Project URL** и ключ **anon public**.

### 2. Подключение

В [index.html](index.html), в начале раздела `<script>`, заполнить две строки:

```js
var SUPABASE_URL = "https://ваш-проект.supabase.co";
var SUPABASE_KEY = "ваш-anon-ключ";
```

Оба значения публичные по устройству Supabase — прямой доступ к таблице закрыт,
данные защищает секрет из ссылки, а не эти ключи.

Пока строки пустые, приложение работает без сервера, только на своём устройстве.

### 3. Публикация (GitHub Pages, бесплатно)

1. Создать репозиторий, залить содержимое этой папки.
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Через минуту адрес готов: `https://<ник>.github.io/<репозиторий>/`

### 4. Ссылка для входа

Аккаунтов и паролей нет. Доступ даёт секрет в адресе:

```
https://<ник>.github.io/<репозиторий>/#k=<секрет из 32 символов>
```

Секрет **не хранится в этом репозитории** — он передаётся отдельно.
При первом открытии он запоминается в браузере, дальше ссылка не нужна:
приложение добавляется на главный экран и запускается как обычное.

Кто получит ссылку, тот увидит данные. В общие чаты её не отправлять.
Если утекла — сгенерировать новый секрет, перенести данные бэкапом,
старую строку удалить из таблицы.

## Перенос данных со старой версии

1. Старое приложение: Настройки → Бэкап → Скопировать
2. Новое: Настройки → Восстановить → вставить → Заменить

## Как устроено хранение

```
изменение → localStorage (мгновенно)
          → через 2 сек тишины → save_space() на сервере
```

При открытии приложение сравнивает время правки у себя и на сервере и берёт
свежее. Нет сети — работает как обычно, отправит при первой возможности.
Полоса под шапкой появляется, только когда есть что сказать: «нет сети»,
«ещё не на сервере».
